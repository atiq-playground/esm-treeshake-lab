Copy-paste from the repo root. The docs site does **not** run the bench.

Home / Quick Facts cite committed `docs/lab/benchmark-*-latest.json` at **research scale** (UC1–UC4 **N=100** landing-shaped, fleet **N=50×M=100**, coldstart **N=50**, 3p **N=100**). CI smoke (`lab:bench:smoke`) is N=3 asserts only and **does not** overwrite those artifacts.

**Call sites:** `--used=K` is how many surface functions the schema **binds** (same K on both arms; K may exceed N). Landing artifacts: **K=200** (~2/pkg lean), **K=300** (~3/pkg fat/cycles), **K=500** (~5/pkg many).

## Smoke (CI only): UC1

```bash
bun run lab:bench:smoke
```

Committed N=3 packages. esbuild + marker asserts. **ESM call sites: 1.** Writes under `tmp/` only — never clobbers published latest.

## Variants

**UC2 wide**: ~20 functions *defined* per service. Bind ~3/pkg with `--used=300`.

```bash
bun run lab:bench:wide -- --n=100 --used=300
bun run lab:bench:wide -- --n=100 --fns=40 --used=300
```

**UC3 cycles**: wide + package ring. Binding resolvers across packages that ring-link can still drag neighbors.

```bash
bun run lab:bench:cycles -- --n=100 --used=300
```

**UC4 partial**: heavier schema (~5/pkg). Optional `--seed=` shuffles which surface fns (reproducible).

```bash
bun run lab:bench:partial -- --n=100 --used=500
bun run lab:bench:partial -- --n=100 --used=500 --seed=42
```
