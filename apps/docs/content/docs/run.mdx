Copy-paste from the repo root. The docs site does **not** run the bench.

Home chart compares **UC1–UC4** from `docs/lab/benchmark-*-latest.json`, framed as a **GraphQL service** whose schema can reach ~100 first-party domain packages. Typical bind is **~2–5 resolvers per package** (1 function ≈ 1 field resolver). CI smoke still writes **UC1 baseline** (`benchmark-latest.*`) at N=3.

**Call sites:** `--used=K` is how many surface functions the schema **binds** (same K on both arms; K may exceed N). Landing artifacts: **K=200** (~2/pkg lean), **K=300** (~3/pkg fat/cycles), **K=500** (~5/pkg many).

## Smoke (CI): UC1

```bash
bun run lab:bench:smoke
```

Committed N=3 packages. esbuild + marker asserts. **ESM call sites: 1.**

## Landing-shaped local (GraphQL)

```bash
bun run lab:bench -- --n=100 --used=200
bun run lab:bench:wide -- --n=100 --used=300
bun run lab:bench:cycles -- --n=100 --used=300
bun run lab:bench:partial -- --n=100 --used=500
```

Optional stress: `bun run lab:bench -- --n=1000 --used=300`.

## Variants

**UC2 wide**: ~20 functions *defined* per service. Bind ~3/pkg with `--used=300`.

```bash
bun run lab:bench:wide -- --n=100 --used=300
bun run lab:bench:wide -- --n=100 --fns=40 --used=300
```

**UC3 cycles**: wide + package ring. Binding resolvers across packages that ring-link can still drag neighbors.

```bash
bun run lab:bench:cycles -- --n=100 --used=300
```

**UC4 partial**: heavier schema (~5/pkg). Optional `--seed=` shuffles which surface fns (reproducible).

```bash
bun run lab:bench:partial -- --n=100 --used=500
bun run lab:bench:partial -- --n=100 --used=500 --seed=42
```

## Extended: third-party ballast + multi-consumer + cold start

Not CI smoke. Sibling reports (do not overwrite UC1).

```bash
# Stub 3p weight (shared @lab/3p-core + unused @lab/3p-extra-*); default 4 × ~32KB ballast
bun run lab:bench:thirdparty -- --n=100
# Tiny local check
bun run lab:bench:thirdparty -- --n=3 --3p-count=2 --3p-bytes=2048
# Real pinned npm (graphql + dataloader / graphql-tag / uuid extras)
bun run lab:bench:thirdparty:real -- --n=100

# M frontend apps: naive ×M + esbuild multi-entry shared (--fleet-mode=both default)
bun run lab:bench:fleet -- --n=50 --consumers=100

bun run lab:bench:coldstart -- --n=50
```
